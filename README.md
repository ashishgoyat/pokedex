# Pokédex App

A simple Pokédex web application built using HTML, CSS, and JavaScript.  
It fetches Pokémon data from the PokéAPI and displays Pokémon based on the selected type and count.

## Features
- Select Pokémon by type  
- Choose number of Pokémon to display  
- Displays Pokémon image, name, moves, attack and defence  
- Dynamic theme based on Pokémon type  

## Technologies Used
- HTML  
- CSS  
- JavaScript  
- PokéAPI  

## How to Run
1. Download or clone the project  
2. Open `index.html` in a web browser  

## API Used
- https://pokeapi.co/
